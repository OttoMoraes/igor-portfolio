# Igor — Portfólio Profissional

Design completo de UI/UX para o portfólio de **Igor**, Editor de Vídeo, Motion Designer e Criador de Conteúdo Visual.

## Objetivo

Transmitir profissionalismo, criatividade, velocidade, confiança e qualidade.  
O visitante deve imediatamente sentir: *"Esse editor é profissional. Quero contratar esse cara."*

## Identidade Visual

| Elemento | Valor |
|----------|-------|
| Branco | `#FFFFFF` |
| Preto | `#111111` |
| Cinza claro | `#F5F5F5` |
| Cinza médio | `#CFCFCF` |
| **Destaque** | `#F4C430` (amarelo moderno) |

O amarelo é usado **apenas** em:
- Botões primários
- Links ativos / labels de seção
- Ícones de destaque
- Hover states
- Badge de disponibilidade

## Tipografia

- **Fonte:** Inter (Google Fonts)
- Hierarquia clara com títulos grandes e espaçamento generoso
- Letter-spacing negativo em headings para visual premium

## Estrutura (Single Page)

1. **Home / Hero** — Nome, especialidades, frase de impacto, CTAs, stats, foto
2. **Sobre** — História, missão/visão/valores, timeline de carreira
3. **Portfólio** — Galeria com filtros (YouTube, Instagram, TikTok, Reels, Shorts, Motion, Publicidade)
4. **Serviços** — 8 cards: Edição, Motion, Color Grading, Áudio, Thumbs, Identidade, Empresas, Redes
5. **Processo** — 6 etapas: Contato → Briefing → Planejamento → Edição → Revisão → Entrega
6. **Depoimentos** — 3 cards de exemplo com estrelas
7. **Contato** — WhatsApp, Instagram, E-mail, Telefone + formulário + disponibilidade
8. **Redes Sociais** — Instagram, YouTube, TikTok, LinkedIn, Behance
9. **FAQ** — Accordion com 5 perguntas frequentes
10. **Rodapé** — Logo, links, contato, redes, copyright, voltar ao topo

## Design System

- Botões (primary / secondary / sm / full)
- Cards (portfolio, service, testimonial, social)
- Inputs + textarea com focus ring amarelo
- Navbar fixa com blur
- FAQ accordion
- Filtros de portfólio
- Timeline
- Processo em steps

## Responsividade

- **Desktop** (>1024px)
- **Tablet** (768–1024px)
- **Mobile** (<768px) com menu hamburger

## Como visualizar

Abra o arquivo `index.html` em qualquer navegador moderno.

```bash
# Ou sirva localmente
npx serve .
```

## Notas de implementação

- Placeholders de imagem prontos para substituir por fotos reais do Igor
- Links de contato e redes sociais com valores de exemplo (substituir)
- Formulário de contato com feedback visual de envio (demo)
- Animações suaves de reveal on scroll
- Filtros de portfólio funcionais
- Menu mobile completo
