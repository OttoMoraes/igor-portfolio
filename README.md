# Igor — Portfólio Profissional

Portfólio moderno, minimalista e premium de **Igor**, Editor de Vídeo, Motion Designer e Criador de Conteúdo Visual.

> Transformando ideias em vídeos que prendem a atenção.

🔗 **Site online:** [https://ottomoraes.github.io/igor-portfolio/](https://ottomoraes.github.io/igor-portfolio/)

---

## Sobre o projeto

Este site foi desenvolvido para transmitir profissionalismo, criatividade, velocidade e confiança.  
O objetivo é que o visitante sinta imediatamente vontade de contratar o profissional.

### Seções do site

- **Home** — Hero com nome, especialidades e call-to-actions
- **Sobre** — História, missão, visão, valores e timeline de carreira
- **Portfólio** — Galeria com filtros por categoria (YouTube, Instagram, TikTok, Reels, Shorts, Motion Graphics, Publicidade)
- **Serviços** — Edição de vídeo, Motion Design, Color Grading, Áudio, Thumbnails, Identidade Visual e mais
- **Processo** — Fluxo de trabalho em 6 etapas
- **Depoimentos** — Área preparada para feedbacks de clientes
- **Contato** — Formulário + WhatsApp, Instagram, e-mail e telefone
- **Redes Sociais** — Instagram, YouTube, TikTok, LinkedIn e Behance
- **FAQ** — Perguntas frequentes em formato accordion

## Publicação (GitHub Pages)

1. Vá em **Settings** → **Pages**
2. Em **Source**, selecione:
   - Branch: `main`
   - Folder: `/ (root)`
3. Clique em **Save**
4. O site ficará disponível em:  
   `https://seu-usuario.github.io/igor-portfolio/`

### Domínio personalizado

1. Compre um domínio (ex: `igor.video`)
2. Configure os registros DNS apontando para o GitHub
3. Em **Settings → Pages → Custom domain**, adicione o domínio
4. Marque **Enforce HTTPS**
